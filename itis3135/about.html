About

This website demonstrates my work for UNC Charlotte's ITIS3135 - Front-End Web Application Development course, taught by Mr. von Briesen. Additional course information, guidelines, and checklists are available on the instructor's course website.

The course provides practical experience in front-end web application development through building multiple websites. These projects introduce different tools and techniques while developing skills in page structure, styling, accessibility, validation, and website management.

figure>

Tools Used in This Course

  • VS Code for writing and organizing code.
  • Emmet within VS Code for creating HTML efficiently.
  • FileZilla for transferring files through SFTP.
  • Git, GitHub Desktop, and GitHub.com for version control.
  • Browser tools for inspecting and debugging web pages.
  • The Accumulus Validator for checking page quality.
